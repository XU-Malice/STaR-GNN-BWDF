## 整理后的两个入口

| 入口（相对于项目） | 用途 |

本工具不会改写历史配置、manifest 或日志中记录的旧绝对路径。应通过归档路径映射定位旧文件。历史流程已结束，归档后的目录用于查询和追溯，不应重新运行旧训练队列或旧权重清理器。后续实验从固定结果目录读取所选模型和设置，另建输出目录。

## 执行与恢复

安装脚本 `scripts/reproduce/install_que_history_organization.sh` 接收完整工具提交号，从 Git 导出到项目外部并运行测试后后台执行。训练工作区提交保持不变。无需 pip 安装或修改训练环境。

工具仅在保存核验通过、清理完成、相关进程及文件锁允许时移动目录。同一文件系统内移动目录，保留文件内容并记录原路径与新路径。开始前检查目标冲突和符号链接，归档后逐文件复核；发生中断可用同一工具继续，不覆盖已有的冲突目录。

查看进度：

```bash
tail -n 30 ~/projects/STaR-GNN-BWDF/logs/que_history_organization_launcher.log
```

出现 `ARCHIVED` 表示目录整理完成。尚未完成时保留原目录及归档记录，按日志查明原因。
