# Manuscript result-figure audit artifacts

These files are generated by `scripts/reproduce/build_manuscript_results_figures.py`.

- `fig1_relative_improvement.csv`: relative reductions in MAE/MAPE/RMSE and absolute NSE gains versus eight baselines.
- `fig2_day1_day7_publisher_mae_ci.csv`: day-wise publisher-compatible MAE and bootstrap 95% CI for the 168 h task.
- `fig2_day1_day7_publisher_mae_metadata.json`: deterministic bootstrap settings and metric definition.
- `fig3_origin_publisher_mae.csv`: per-origin publisher-compatible MAE for 46 common test origins.
- `fig4_dma_mae_improvement.csv`: DMA-level STaR-GNN MAE reduction versus DCRNN/STGCN.
- `fig5_representative_168h_trajectory.csv`: observed/predicted aggregate-demand trajectory for the pre-specified median-error origin.
- `fig5_representative_168h_selection.json`: exact selection rule, origin index, and model errors.
