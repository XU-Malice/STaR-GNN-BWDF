# 3. 结果与讨论

## 3.1 不同预测时域下的总体性能及空间一致性

为评价 STaR-GNN 的性能增益是否超越单一建模范式，本文构建了由时序预测到时空图预测的递进式比较。GRU、LSTM、MSNet、MSCMNet-WM、MSCMNet-M 和 MSCMNet-W 主要刻画需求序列的时间依赖与多尺度变化，DCRNN 和 STGCN 则进一步引入 DMA 之间的关联结构。六种时序模型的结果来自已有研究，因此用于确定 STaR-GNN 在现有方法中的总体位置。涉及组件贡献、预测起点和统计不确定性的推断，则仅基于本文统一实验协议下获得的结果。

[Table 1](tables/submission/table1_overall_performance.md) 给出了两个预测时域的绝对性能。STaR-GNN 在 24 h 和 168 h 任务的 MAE、MAPE、RMSE 和 NSE 上均取得最优结果，说明其优势并未局限于特定指标或预测尺度。时序模型中，MSCMNet-W 的综合性能最具竞争力。对于 24 h 预测，STaR-GNN 的 MAE 约为该模型的三分之二，MAPE 由 2.600% 降至 1.805%。当预测时域延长至 168 h 后，相较于图模型中整体表现更优的 DCRNN，STaR-GNN 的 MAPE 和 RMSE 均降至原有水平的约六成，NSE 由 0.940 提高至 0.976。由此可见，模型不仅提高了日前预测精度，对周尺度误差累积也表现出更强的抑制能力。

Fig. 1 进一步比较了相对于各基线的改善幅度。热图中所有单元均为正值，三项误差指标的降幅均超过 16%，最大降幅接近 47%，表明性能增益广泛存在于两类基线和两个预测时域。24 h 任务中，相较于 LSTM 的 MAE 改善最为显著。168 h 任务中，相较于 STGCN 的 MAPE 降低约 44%，NSE 提高 0.043。值得注意的是，随着预测时域延长，相对于 DCRNN 和 STGCN 的 MAPE 与 RMSE 改善反而扩大。这一变化说明，STaR-GNN 的优势并非依赖短时序列的局部拟合，而更可能与其对跨日需求状态和位置相关周期模式的表征有关。

![不同预测时域下 STaR-GNN 相对基线模型的总体性能改善](figures/submission/main_fig1_overall_performance.png)

**Fig. 1. 不同预测时域下 STaR-GNN 相对基线模型的总体性能改善。** 图中分别给出 MAE、MAPE 和 RMSE 的相对降幅以及 NSE 的绝对提升，正值表示 STaR-GNN 优于相应基线。各模型的绝对指标见 Table 1。

系统总体指标仍可能掩盖分区差异，因而 Fig. 2 将比较下沉到 DMA 尺度。24 h 任务中，大多数散点位于零线右侧，各模型对应分布的中位数也均保持为正，说明 Table 1 中的总体优势并非由少数分区主导。Supplementary Table S1 对这一图形特征给出了精确核验。在十个 DMA、八种基线和四项指标形成的 320 个比较中，306 个结果有利于 STaR-GNN，占 95.6%。相对于 DCRNN 和 STGCN 的 80 个比较则全部位于有利方向。改善因而同时覆盖了不同 DMA、评价指标和模型类型。

周尺度下，各分布的中位数仍位于零线右侧，但散点和四分位距普遍向两侧扩展，尤其是部分时序基线出现了更多接近或越过零线的结果。这表明平均优势得以保留的同时，不同 DMA 对长预测时域的响应开始分化。Supplementary Table S1 显示，168 h 任务中有 275 个比较保持有利，占 85.9%。与两个图基线比较时，80 个结果中有 78 个仍优于基线。仅 DMA G 相对于 STGCN 的 RMSE 和 NSE 未得到改善，前者增加 1.25%，后者降低 0.003。两个差值均十分接近零，因而不会改变分布中心和离散程度所显示的总体格局，具体身份与数值由 Supplementary Table S1 提供。

![STaR-GNN 相对各基线模型的跨 DMA 改善分布](figures/submission/main_fig2_dma_performance.png)

**Fig. 2. STaR-GNN 相对各基线模型的跨 DMA 改善分布。** 小点表示单个 DMA，较大标记和水平线段分别表示十个 DMA 的中位数与四分位距。圆形和方形分别对应 24 h 与 168 h 预测，零线右侧表示 STaR-GNN 优于相应基线。误差指标采用相对降幅，NSE 采用绝对差值。水平分隔线区分时序基线与图基线，完整的 DMA 级指标见 [Supplementary Table S1](tables/submission/tableS1_dma_metrics.md)。

广泛优于固定基线并不意味着在每个 DMA 上都排名第一，因为局部最强竞争模型会随分区、指标和预测时域改变。Fig. 3 因而将比较标准提高到每个位置表现最好的非 STaR-GNN 模型。24 h 任务中，DMA B 至 DMA J 的四项指标均位于零线右侧，只有 DMA A 在四个面板中均未跨越局部竞争边界。根据 Supplementary Tables S1 和 S2，STaR-GNN 在九个 DMA 的四项指标上均排名第一。对三项误差相对于各自第二名的改善先在 DMA 内取均值，再在上述分区间取中位数，领先幅度为 17.5%。这种优势并非均匀分布。DMA C 和 DMA E 的平均误差改善分别为 35.1% 和 23.0%，而 DMA D 和 DMA J 仅为 2.1% 和 2.8%。因此，日前预测呈现的是覆盖广泛但幅度不同的领先格局，其中部分 DMA 已接近局部最强模型的性能边界。

168 h 任务中，图中橙色标记增多，说明局部失利随预测时域延长而扩展。Supplementary Tables S1 和 S2 进一步表明，STaR-GNN 仍在 DMA B、C、D、F、H 和 J 的四项指标上保持第一，在 DMA I 的三项误差指标上排名第一，而其 NSE 位列第二。对于六个全面领先的 DMA，三项误差相对于第二名的平均改善中位数降至 10.4%。DMA C 和 DMA J 仍保持 15.8% 和 14.7% 的平均误差优势，DMA D 则收窄至 1.1%。与此相对，DMA A、E 和 G 未在任何指标上达到局部最优。由此形成的空间收缩比总体均值更能揭示周尺度任务的难点。STaR-GNN 仍在多数 DMA 上跨越局部竞争边界，但优势的覆盖和幅度均有所减弱，这自然引出下一问题，即哪些模型设计维持了长预测时域下的领先，以及这种贡献是否随预测位置而变化。

![STaR-GNN 相对局部最强竞争模型的 DMA 级幅度](figures/submission/main_fig3_dma_local_margin.png)

**Fig. 3. STaR-GNN 相对局部最优竞争模型的 DMA 级性能幅度及其随预测时域的变化。** 每个 DMA 在不同指标和预测时域下均与表现最好的非 STaR-GNN 模型比较。灰线连接同一 DMA 的两个预测时域，橙色标记表示 STaR-GNN 未超过局部最优竞争模型。局部竞争模型和精确差值见 [Supplementary Table S2](tables/submission/tableS2_dma_local_margin.md)，完整排名可由 Supplementary Table S1 核验。

## 3.2 模型组件的贡献及其提前期依赖性

[Table 2](tables/submission/table2_factorial_ablation.md) 通过双因素消融区分 SAS-Norm 与 FA-DPR 的独立作用和组合效果。24 h 任务中，单独引入任一组件均改善了 DCRNN 的四项指标，其中 SAS-Norm 对 MAE 的降低更明显，FA-DPR 对 MAPE 和 RMSE 的改善相对突出。两者共同使用后，STaR-GNN 在三项误差和 NSE 上均取得最优结果。这说明两个组件提供了互补信息，日前性能并非由其中一个结构单独产生。

预测时域延长至 168 h 后，两个组件的作用出现明显分化。SAS-Norm 将 DCRNN 的 MAPE 从 3.248% 降至 2.102%，并将 NSE 从 0.940 提高至 0.974，是周尺度增益的主要来源。FA-DPR 虽然降低了 MAE 和 RMSE，但 MAPE 略有增加，表明其独立贡献依赖评价指标。完整模型在 MAPE、RMSE 和 NSE 上进一步取得最优结果，其 MAE 为 12.234，与仅使用 SAS-Norm 时的 12.208 十分接近。更准确的解释因而不是两个组件在所有指标上简单叠加，而是 SAS-Norm 建立了稳定的长时域性能基础，FA-DPR 在与其协同时补充改善部分误差结构。

Fig. 4 揭示了这种分工如何沿预测提前期演化。随着预测从第 1 天推进至第 7 天，完整模型相对于 DCRNN 的 MAE 改善由约 13% 扩大到 34%，仅使用 SAS-Norm 时呈现近乎平行的增长轨迹。MAPE、RMSE 和 NSE 也表现出相同的总体关系，SAS-Norm 与完整模型的改善大多随提前期保持或扩大，FA-DPR 的均值则在一周中后段出现波动，且多个置信区间跨越零线。由此可见，日状态分离与恢复主要作用于跨日误差累积，其价值会在预测位置远离起点后逐步显现。FA-DPR 的作用更具条件性，可能有助于匹配位置相关的周期模式，但现有消融证据尚不足以把历史日检索认定为性能改善的直接因果机制。

![SAS-Norm 与 FA-DPR 的逐日贡献](figures/submission/main_fig4_ablation_leadtime.png)

**Fig. 4. SAS-Norm 与 FA-DPR 在 168 h 预测中的逐日贡献。** 各变体均在相同测试起点和预测日上与 DCRNN 比较。点表示 46 个共同预测起点的平均改善，误差线表示采用七起点移动块自助法估计的 95% 置信区间。正值表示相应变体优于 DCRNN。

## 3.3 不同预测起点与需求波动条件下的稳健性

前两节说明了 STaR-GNN 在模型类型、DMA 和预测提前期上的优势，但总体指标仍会平均掉测试期内的时间差异。Fig. 5 因而转向预测起点层面的配对比较，检验性能提升是否贯穿不同预测窗口。这里的比较集合与 Table 1 不同，原因在于两个问题需要不同证据。Table 1 纳入全部基线，用于确定 STaR-GNN 相对于时序模型和图模型的总体位置。逐起点推断则要求模型具有完全一致的数据划分、输入、预测起点和原始输出，才能计算配对改善及其块自助置信区间。已有研究仅报告了 GRU、LSTM、MSNet 和 MSCMNet 系列的总体及 DMA 级汇总指标，并未提供与本文 46 个共同预测起点对应的预测序列，因此不能将其与同协议的逐起点结果混合。

在满足上述条件的模型中，DCRNN 和 STGCN 分别代表循环式与卷积式时空图建模。Fig. 5 将二者与 STaR-GNN 比较，不是重新进行一次缩小范围的模型排名，而是在控制图结构使用和评价流程后，检验性能增益是否来自 STaR-GNN 的特定设计，而非仅仅来自引入 DMA 关联。考虑到相邻周尺度窗口存在重叠，置信区间采用有序移动块自助法估计，以保留预测起点之间的时间依赖。

24 h 任务中，Fig. 5a 和 Fig. 5c 的 MAE 散点几乎全部位于零线右侧，其均值和置信区间也与零线保持明显距离。Supplementary Table S3 显示，相对于 DCRNN 和 STGCN，STaR-GNN 均在 46 个起点中的 45 个取得更低 MAE，平均降幅分别为 19.3% 和 22.6%。相对于 STGCN，其余三项指标的平均改善也均获得置信区间支持。相对于 DCRNN 时，MAPE 和 RMSE 的均值虽为正，但置信区间跨越零线，说明日前任务中的 MAE 优势最为稳定，而其他指标仍受局部误差结构影响。

周尺度下，Fig. 5b 和 Fig. 5c 中相对于 DCRNN 的分布整体右移，且左侧不利点显著减少。Supplementary Table S3 的精确统计表明，STaR-GNN 在全部 46 个起点上均降低 MAE，MAPE、RMSE 和 NSE 仅各有一个起点未改善，四项平均效应的置信区间均位于有利方向。相对于 STGCN 时，MAE、MAPE、RMSE 和 NSE 分别在 40、36、35 和 35 个起点上占优，平均效应同样得到置信区间支持。周尺度提升因而不是少数易预测窗口造成的平均效应，而是在测试期的大部分时段均可观察到。与此同时，领先起点的数量随参照模型改变，也说明 STGCN 在部分周窗口仍构成更强的局部竞争者。

Fig. 5d 进一步将分析集中到根据观测需求预先识别的十二个高波动起点。在这些困难窗口中，相对于 DCRNN 的 MAE 在两个预测时域均全部改善，168 h 任务的其余三项指标也各有十一个起点保持优势。相对于 STGCN 时，168 h 任务的 MAE 仅在七个起点占优，其余三项指标各在九个起点占优。图中的胜出次数与 Supplementary Table S3 的平均效应共同表明，STaR-GNN 对需求波动具有一定稳健性，但相对于较强图基线的优势会在快速变化条件下收窄。性能优势由此可以被概括为在多数时间窗口中稳定存在，而不是在所有困难样本上无条件成立。

![STaR-GNN 在不同预测起点和高波动需求窗口中的稳健性](figures/submission/main_fig5_origin_robustness.png)

**Fig. 5. STaR-GNN 在不同预测起点和高波动需求窗口中的稳健性。** 图中给出 24 h 与 168 h 任务下逐起点的误差改善、NSE 提升及其块自助置信区间，并汇总高波动窗口中的领先次数。高波动窗口由观测需求的归一化平均绝对变化幅度确定。完整统计见 [Supplementary Table S3](tables/submission/tableS3_forecast_origin_robustness.md)。

## 3.4 周尺度需求动态、应用意义与研究边界

逐起点分析回答了优势在时间上是否稳定，却没有显示误差发生在一周需求过程的哪些位置。Fig. 6 因而沿用具有共同原始输出的三种模型，将同一批 168 h 预测进一步展开为日内误差、代表性周轨迹和逐小时偏差。Fig. 6a 中，STaR-GNN 的误差曲线在几乎所有小时都位于 DCRNN 和 STGCN 下方，且较大的差异并未集中在单一低需水时段。对全部共同起点和七个预测日汇总后，系统总需水平均绝对误差为 4.920 L s\(^{-1}\)，低于 DCRNN 的 7.735 L s\(^{-1}\) 和 STGCN 的 8.574 L s\(^{-1}\)。这些精确汇总值见 Supplementary Table S4。

代表性预测周依据 STaR-GNN 误差最接近全部起点中位数的规则预先确定，而不是根据曲线外观挑选。Fig. 6b 表明，三种模型均能重现基本日周期，但 STaR-GNN 对跨日需求水平转换和多数局部峰谷的跟踪更接近观测。Fig. 6c 进一步显示，剩余较大偏差主要出现在需求快速上升或下降的时段。该现象与 Fig. 5 中高波动窗口相对于 STGCN 的优势收窄相呼应，也与 Fig. 4 所示 SAS-Norm 的长提前期贡献一致。综合这些证据可以推断，STaR-GNN 的周尺度优势主要来自对跨日状态变化的显式处理，而不是单纯提高对平稳日周期的拟合能力。这一解释由消融结果和过程曲线共同支持，但仍属于模型行为层面的推论，不能替代对用水变化物理驱动因素的直接验证。

![群体日内误差与代表性 168 h 需水预测](figures/submission/main_fig6_week_ahead_dynamics.png)

**Fig. 6. 群体日内误差与代表性 168 h 需水预测。** 图中依次展示全部共同测试起点聚合后的日内系统总需水绝对误差、按中位误差接近原则选取的代表性周预测轨迹，以及同一窗口的逐小时绝对误差。阴影表示采用七起点移动块自助法估计的 95% 置信区间，需求与误差单位均为 L s\(^{-1}\)。总体汇总值和代表性窗口选择规则见 [Supplementary Table S4](tables/submission/tableS4_week_ahead_dynamics.md)。

总体而言，本文的证据链从系统平均性能逐步推进到空间覆盖、局部竞争边界、组件贡献、预测起点和逐小时需求动态。Que et al. (2024) 与 Lin et al. (2025) 的多时间尺度需水研究同样表明，模型的相对性能会随预测尺度改变，周尺度预测不能被视为日前任务的简单延伸。Xue and Zhu (2025) 对图水文预测的研究进一步说明，仅依赖总体指标难以识别节点和空间关系上的局部差异。本文在此基础上表明，STaR-GNN 的总体优势在长预测时域仍然成立，但 DMA 级竞争边界和高波动窗口揭示了这种优势的空间与时间条件。SAS-Norm 对逐日改善轨迹的主导作用则进一步支持在多 DMA 预测中显式区分跨日需求状态与日内变化形态。

从运行应用看，更准确的日前预测可为短期制水和泵组计划提供依据，周尺度预测则有望支持蓄水安排、检修计划和跨区域资源协调。STaR-GNN 在多数 DMA、预测起点和日内小时位置上的改善，显示了其服务多分区协同预测的潜力。然而，本文并未将预测结果接入调度或经济优化模型，因此不能直接推断其能够降低实际能耗或运行成本。DMA A、E 和 G 的局部失利，以及高波动条件下相对于 STGCN 的优势收窄，也说明实际应用仍需保留分区级误差监测和异常需求预警，不能仅依据系统总量评价模型。

这些结论仍受研究范围限制。实验仅基于一个真实多 DMA 供水系统，模型在其他城市、气候条件和用水结构下的可迁移性仍需外部数据验证。本文采用由历史需水相关性构建的静态功能图，该图不能等同于完整水力拓扑，也无法反映运行状态变化引起的动态关联。部分时序模型采用已有研究公开结果，因而跨来源比较仅用于性能定位，严格的配对统计只适用于本文统一协议下训练和评价的模型。此外，当前研究聚焦确定性点预测，尚未系统评估预测不确定性、传感器缺测和罕见异常事件的影响。这些限制不改变当前系统内的比较结论，但界定了模型推广和投入运行前仍需验证的范围。
